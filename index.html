Selected research

  • SASD: Source-Aware Self-Distillation

    In progress

    Training-time defense against prompt injection

    A multi-teacher KL-divergence distillation objective that trains the model to tell trusted instructions apart from injected content in context.

  • Qalb Post-Train

    Completed

    Urdu mathematical reasoning via RL with verifiable rewards

    Urdu chain-of-thought reasoning trained on an 8B model with a rule-based reward and no judge model, evaluated on GSM8K-Urdu.

  • shellsim

    Completed

    Terminal agent RL against a learned world model

    A terminal agent trained with GRPO against a language model that simulates the shell. Each task is scored by a rule-based verifier.
